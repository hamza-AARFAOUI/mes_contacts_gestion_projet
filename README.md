# Gestionnaire de Contacts CLI

## Présentation

++Gestionnaire de Contacts CLI est une application en ligne de commande développée en Python. Elle permet de gérer un répertoire de contacts de manière simple et organisée.

## Fonctionnalités

- Ajouter un nouveau contact.
- Afficher la liste des contacts.
- Supprimer un contact à partir de son identifiant.
- Enregistrer les contacts dans un fichier texte.
- Charger automatiquement les contacts au démarrage.
- Gérer les erreurs de saisie.

## Technologies utilisées

- Python 3
- Git
- GitHub
- Fichiers texte (`contacts.txt`)

```bash
cd mes_contacts_gestion_projet
```

